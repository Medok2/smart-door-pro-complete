## 1️⃣ التثبيت على الاستضافة

### المتطلبات

- استضافة PHP 8.1+
- MySQL 5.7+ أو MariaDB 10.2+
- دعم HTTPS (موصى به)
- صلاحيات الكتابة على `/var/www/html`

### خطوات التثبيت

#### الخطوة 1: تحميل الملفات

```bash
cd /var/www/html
unzip smart-door-pro-hosting.zip
cd smart-door-pro
chmod 755 . -R
```

#### الخطوة 2: إعداد قاعدة البيانات

```bash
# الاتصال بـ MySQL
mysql -u root -p

# أو عبر PhpMyAdmin
Admin Panel > Database > New Database
```

#### الخطوة 3: تشغيل المثبت

```bash
# عبر المتصفح
https://yourdomain.com/smart-door/install.php

# أو عبر CLI
php install.php
```

**الرسالة الناجحة:**
```
✓ Database tables created successfully
✓ Default admin created: admin@smartdoor.com
⚠ WARNING: Change password immediately after first login!
✓ Installation complete!
```

#### الخطوة 4: إعداد التكوين

```bash
# نسخ ملف المثال
cp config.example.php config.php

# تحرير الملف
nano config.php
```

**التعديلات المطلوبة:**

```php
// قاعدة البيانات
define('DB_HOST', 'localhost');
define('DB_USER', 'your_db_user');
define('DB_PASS', 'your_db_password');
define('DB_NAME', 'smart_door');

// الخادم
define('SERVER_URL', 'https://yourdomain.com');
define('JWT_SECRET', 'your-random-secret-key-here');

// Telegram (اختياري)
define('TELEGRAM_BOT_TOKEN', 'your_bot_token');
define('TELEGRAM_ADMIN_CHAT_ID', 'your_chat_id');
```

#### الخطوة 5: الأمان

```bash
# منع الوصول المباشر لملفات التكوين
echo "Deny from all" > config.php.htaccess

# تحديث صلاحيات الملفات
find . -type f -name '*.php' -exec chmod 644 {} \;
find . -type d -exec chmod 755 {} \;
```

#### الخطوة 6: اختبار التثبيت

```bash
curl https://yourdomain.com/api/v1/health
```

**الرد المتوقع:**
```json
{
  "ok": true,
  "data": {
    "status": "ok",
    "version": "1.0.0",
    "database": {"status": "connected"},
    "device": {"online": false}
  }
}
```

## 2️⃣ إعداد Wemos D1 Mini

### المتطلبات

- Wemos D1 Mini ESP8266
- كابل USB Micro
- محرر Arduino IDE أو PlatformIO
- Arduino ESP8266 Board Package 3.1.0+

### الخطوة 1: تثبيت المحرر

```
1. فتح Arduino IDE
2. File > Preferences
3. في "Additional Boards Manager URLs" أضف:
   https://arduino.esp8266.com/stable/package_esp8266com_index.json
4. Tools > Board > Boards Manager
5. ابحث عن "ESP8266"
6. اضغط Install
```

### الخطوة 2: اختيار اللوحة

```
Tools:
  Board: Wemos D1 Mini
  Upload Speed: 115200
  CPU Frequency: 80 MHz
  Flash Size: 4M (3M SPIFFS)
  Port: COM3 (أو /dev/ttyUSB0)
```

### الخطوة 3: رفع Firmware

```bash
# نسخ SmartDoorESP8266.ino إلى مجلد
# ثم:
1. فتح ملف SmartDoorESP8266.ino
2. Sketch > Verify/Compile
3. Sketch > Upload
```

**الانتظار حتى:**
```
leaving...
soft resetting...
✓ Upload complete
```

### الخطوة 4: التحقق من الاتصال

```bash
# فتح Serial Monitor
Tools > Serial Monitor (115200 baud)

# ستظهر الرسائل:
[Boot] GPIO initialization
[GPIO] D2 set to SAFE state (OFF)
✓ WiFi initialized
✓ Boot complete - Entering SAFE_OFF state
```

### الخطوة 5: إعادة تشغيل

```
اضغط زر Reset على اللوحة
أو:
اقطع USB مدة 2 ثانية
```

## 🔟 النسخ الاحتياطي والاستعادة

unzip smart-door-backup-2024-09-01.zip -d /var/www/html/
php install.php  # إذا لم توجد الجداول

## 📊 جداول الحدود

### الحدود المحلية (ESP8266)

| الحد | القيمة | الملاحظات |
|-----|--------|----------|
| المستخدمون | 30 | محفوظ في EEPROM |
| الأجهزة | 16 | محفوظ محلياً |
| مدة الفتح | 500-30000 ms | 3000 ms افتراضي |
| حجم EEPROM | 4 KB | 256 bytes للإعدادات |

### الحدود السحابية

| الحد | القيمة | الملاحظات |
|-----|--------|----------|
| المستخدمون | Unlimited | Pagination 50 |
| QR Codes | Unlimited | Pagination 100 |
| السجلات | Unlimited | Pagination 50 |
| الأوامر | 1000/ساعة | Rate limiting |
